How to contribute

The manuscripts live in the GitHub repository mathcommunity/oai-math-revised. To contribute you need a free GitHub account. It does not have to show your real name: you can create a separate account just for this. Maintainers review everything that is submitted. Some papers have a curator, who is the point of contact for that paper and considers proposed edits.

Report a problem or suggest a correction. Use the "Report a problem" button on the paper's page. Say where in the paper (section, theorem) and what is wrong or unclear.

Add a reference, follow-up work or expert comment. Use the "Add a reference or comment" button on the paper's page, or edit the paper's NOTES.md directly. Use links; reproduce other people's comments only with their permission.

Discuss a paper. Each paper can have one discussion thread on GitHub for questions, explanations and reading notes. The button on the paper's page opens it, or starts it if there is none yet.

Work on a paper with others. Use the "Interested in working on this" button on the paper's page, or add your name to NOTES.md. Add only your own name, or names you have explicit permission to add.

Edit a manuscript. Edits should be small and local: missing references, clearer definitions, an explained step, a repaired error. Rewrites and substantial new expositions belong in separate works, which the paper's notes can link to (see About). Fork the repository, edit the TeX in preprints/<paper>/build/, recompile the PDF, and open a pull request. Please disclose substantial use of language models, proof assistants or other software. The repository README has more details.

Credit. Each accepted change gets a line under "Contributions" in the paper's NOTES.md, with the date, your GitHub handle and what changed, for example - 2026-10-20 @your-handle: Added a reference to Smith (1990) ([PR #12](link)). Add it in your pull request, or a maintainer will. You may add your name after the handle: @your-handle (Your Name). These lines appear on the paper's page and under Activity.

AI assistance. Each issue form asks whether maintainers may use AI tools to draft a change addressing your issue. You choose; a person reviews every proposed change either way.
